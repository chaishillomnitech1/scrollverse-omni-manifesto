# Contributing to ScrollVerse Omni Manifesto

Contributions should make the source record more useful, more legible, and easier for a reader to inspect independently.

## Accepted contributions

You may propose a public source link, a correction to a repository name or category, a clearer reader path, an accessibility improvement, or an update to a source’s operating-state label. Every proposal should identify the source URL, the date observed, the requested change, and why the present record should be corrected.

## Source-label rule

Do not submit credentials, private keys, recovery codes, wallet seeds, payment configuration, personally identifying data, unpublished media, private repository content, copyrighted third-party material without a documented purpose and authorization, or instructions that execute an external transaction, deployment, account change, or provider action.

## Review standard

Each accepted record must state whether it is a public source, local validation result, owner-provided visual record, or directly verified external state. A source description alone should not be upgraded into a deployment, rights, financial, provider, payment, product, or release outcome.

## Correction path

If a source’s title, link, visibility, category, or interpretation is inaccurate, open a correction issue or submit a pull request that preserves the prior record and explains the revision. The objective is an open, auditable record rather than an argument about a reader’s conclusion.
