# ScrollVerse Omni Manifesto

**A reader-directed public source index for the ScrollVerse ecosystem.**

ScrollVerse Omni Manifesto organizes owner-authorized public source material into a single, navigable record. It connects project lineage, creative-production planning, learning pathways, portal concepts, music and rights research, commerce readiness, governance methodology, and developer tooling without asking readers to accept a source description as a completed external outcome.

## How to read this repository

Each entry is labeled as an **owner-authorized public source**. The entry records where a reader can inspect the repository and which ScrollVerse pathway it may inform. A public repository, README, description, design, contract, or workflow is not by itself a statement that a service is deployed, a product is for sale, a payment method is active, a contract is live, or a financial result has occurred.

> **Influence is currency. Power without principle is poison.**

The public index currently documents the **52 repositories returned by GitHub’s unauthenticated public API** during the source review. The owner-supplied GitHub account screen shows **73 total repositories**. Those are different scopes: the account total is retained without reduction, while this index only catalogues the public-API source subset available to passive review.

## Reader choice

This repository does not create a checkout, payment method, token sale, market, payout, product listing, contract deployment, or provider configuration. It preserves the material, source path, date, scope, and correction route so readers can explore freely and decide for themselves.
